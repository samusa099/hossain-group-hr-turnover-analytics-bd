# Project Description

## Business Scenario

Hossain Group wants a consistent employee-turnover monitoring system. The HR Business Executive is responsible for converting employee joining and exit records into actionable retention insights.

## Business Questions

1. What is the current period and annualized employee turnover rate?
2. Which departments have the highest turnover?
3. Which exit reasons are most common?
4. How is turnover changing month by month?
5. What risk category should HR report to management?
6. Which departments require stay interviews, compensation review, manager coaching, or workforce planning?

## Deliverables

- Formula-driven Excel turnover calculator
- Excel management dashboard
- Power BI Project (`.pbip`) with semantic model and report definition
- Power BI-ready processed CSV files
- Looker Studio-ready flat CSV
- Kaggle notebook
- GitHub-ready documentation
- Kaggle dataset metadata
- Data dictionary and validation script

## HR Decision Use

The dashboard is intended to support retention reviews, manpower planning, recruitment demand forecasting, exit-interview analysis, department benchmarking, and management reporting.

## Data Ethics

All names and records are synthetic. The project must not be represented as confidential or real Hossain Group employee data.
