# Looker Studio Setup

1. Open Looker Studio.
2. Create a new data source.
3. Select **File Upload**.
4. Upload `hossain_group_looker_studio.csv`.
5. Set `MonthStart` as a date.
6. Set `TurnoverRate` and `AnnualizedTurnoverRate` as percentages.
7. Recommended visuals:
   - Scorecards: Exits, Hires, Average Headcount
   - Time series: TurnoverRate by MonthStart
   - Bar chart: TurnoverRate by Department
   - Table: Department, Exits, AverageHeadcount, RiskLevel
