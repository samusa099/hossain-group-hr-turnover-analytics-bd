Kaggle publishes directory archives using `--dir-mode zip`. The expected visible package contains `raw.zip`, `processed.zip`, `metadata.zip`, `project.zip` and `case-study.zip` plus the approved top-level documentation.

## Explicit exclusions

The release must not add any of the following to the Kaggle package:

- participant submissions;
- `.github/` workflows or administration files;
- repository rulesets;
- Power BI `.pbix` binaries;
- real employee or confidential organisational data;
- secrets, tokens, private keys or environment files;
- duplicate employee datasets;
- generated solution or model-answer files.
